# مداد التحايا — منصة الدعوات الإلكترونية

واجهة عربية متجاوبة لنموذج متجر دعوات إلكترونية موجّه للسوق السعودي. يغطي المشروع رحلة العميل، نموذج دعوة للضيف، تأكيد الحضور، بطاقة QR، لوحة العميل، لوحة الإدارة، والتحقق عند بوابة المناسبة.

> **حالة المشروع:** واجهة MVP قابلة للعرض والاختبار. الدفع، إرسال واتساب، المصادقة، التخزين المركزي، وصلاحية الرابط لمرة واحدة ما زالت تحتاج خدمة خلفية قبل الإطلاق التجاري.

## التشغيل محليًا

لا يحتاج المشروع إلى بناء أو تثبيت حزم. شغّل خادمًا محليًا من جذر المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

للتحقق من سلامة المراجع والملفات:

```bash
npm test
```

## قرار رحلة أرقام الضيوف

يعتمد النموذج الحالي المسار الأنسب لمرحلة الإطلاق الأولى:

1. يختار العميل الباقة ويُدخل بيانات المناسبة.
2. يدفع ويظهر الطلب في لوحة الإدارة.
3. يتواصل المشرف مع العميل عبر واتساب لاستلام قائمة الضيوف.
4. يرفع المشرف القائمة، يراجع الأرقام ويستبعد المكرر أو غير الصالح.
5. يعتمد العميل التصميم، ثم ينفذ المشرف الإرسال من لوحة الإدارة.

هذا القرار يقلل أخطاء العميل والرسائل غير المرغوبة، مع إبقاء إضافة ذاتية للضيوف كميزة مستقبلية.

## بيانات الدخول التجريبية

- الإدارة: `lolotiga2001@gmail.com` وكلمة المرور `111000`.
- العميل: رقم الجوال `0537933514` ثم رمز العرض `1234`.
- لوحة الإدارة وبوابة الدخول محميتان بجلسة إدارة تجريبية، ولوحة المناسبة محمية بجلسة عميل تجريبية.

هذه المصادقة تعمل داخل المتصفح باستخدام `localStorage` لغرض العرض فقط. لا تنشر بيانات ثابتة في نسخة الإنتاج؛ استخدم مصادقة خادمية، كلمة مرور مجزأة، جلسات آمنة، وOTP حقيقي للعميل.

## ملاحظات أمنية ضرورية

- لا تضع رقم الجوال أو اسم الضيف داخل QR؛ استخدم رمزًا عشوائيًا موقّعًا لا يكشف البيانات.
- لا يمكن منع لقطة الشاشة أو إعادة توجيه صورة واتساب تقنيًا بشكل مضمون. الحماية الصحيحة هي ربط الرمز بضيف واحد، التحقق من حالته على الخادم، ومنع تسجيله مرتين.
- اجعل استخدام رابط RSVP عملية ذرّية على الخادم: أول طلب ناجح يحفظ الرد ويغلق الرمز. `localStorage` في هذا المشروع مجرد محاكاة مرئية.
- لا تخزّن بيانات البطاقة في الواجهة. استخدم صفحة دفع مستضافة أو مكونات مزود دفع معتمد، وتحقق من Webhook موقّع على الخادم.
- استخدم WhatsApp Business Platform الرسمي أو مزودًا رسميًا، وقوالب رسائل معتمدة وموافقة واضحة من العميل. لا تعتمد على أدوات تحاكي WhatsApp Web.
- أضف مصادقة متعددة العوامل للإدارة، صلاحيات حسب الدور، وسجل تدقيق لكل رفع وإرسال وتسجيل دخول.
