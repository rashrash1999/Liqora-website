# عمليات Firebase المنفذة

تُستدعى العمليات عبر Firebase Callable SDK. تتحقق Firebase من ID Token وApp Check، ثم تُراجع حالة الحساب وصلاحياته الحالية في الدوال. لا تعتمد الدوال على أدوار أو أسعار قادمة من واجهة العميل.

| العملية                  | الصلاحية                           | النتيجة                                            |
| ------------------------ | ---------------------------------- | -------------------------------------------------- |
| `createOrder`            | عميل موثق برقم الجوال              | إنشاء طلب بسعر خادمي؛ `requestId` يمنع التكرار     |
| `saveReminderPreference` | صاحب الطلب                         | حفظ طلب تذكير، دون إرسال أو جدولة وهمية            |
| `prepareUpload`          | صاحب الطلب للمرجع، الإدارة للتصميم | حجز مسار وحجم ونوع ومدة صلاحية الرفع               |
| `registerUpload`         | صاحب الحجز وصلاحية الطلب           | فحص الملف وربطه بالطلب                             |
| `approveDesign`          | صاحب الطلب                         | اعتماد نسخة التصميم الحالية فقط                    |
| `importGuests`           | الإدارة                            | فحص الأسماء والأرقام والمرافقين والعدد والتكرار    |
| `issueInvitations`       | الإدارة                            | إصدار/تجديد روابط بحد 100 ضيف، بعد الدفع والاعتماد |
| `getInvitation`          | رمز دعوة صالح وApp Check           | أقل بيانات العرض اللازمة للضيف وبطاقته إن أكد      |
| `submitRsvp`             | رمز دعوة صالح وApp Check           | حفظ رد واحد بمعاملة ذرية                           |
| `getGateAssignments`     | الإدارة أو موظف استقبال            | المناسبات المسموح بها للحساب                       |
| `verifyTicket`           | الإدارة أو موظف معين للمناسبة      | التحقق من البطاقة دون تسجيل الدخول                 |
| `checkInTicket`          | الإدارة أو موظف معين للمناسبة      | تسجيل دخول واحد دون مضاعفة العداد                  |
| `createPaymentSession`   | صاحب الطلب                         | خطأ واضح: مزود الدفع غير مفعّل؛ لا يُغيّر الحالة   |
| `sendInvitations`        | الإدارة                            | خطأ واضح: الإرسال الآلي غير مفعّل                  |
| `scheduleReminders`      | الإدارة                            | خطأ واضح: التذكير الآلي غير مفعّل                  |

الأخطاء الأساسية: `unauthenticated` و`permission-denied` و`invalid-argument` و`failed-precondition` و`already-exists` و`not-found` و`resource-exhausted`.

تعمل عمليات الاستيراد وإصدار الروابط والرد والدخول داخل معاملات Firestore. القراءة المباشرة للواجهة مقيدة بقواعد Firestore؛ جميع الكتابات المباشرة مرفوضة حتى للإدارة. Admin SDK يتجاوز القواعد، لذلك تعيد كل دالة تنفيذ التحقق من الهوية والملكية والانتقال المسموح.

تُستخدم دعوة ذات رمز عشوائي 256 بت في fragment الرابط (`#token=`)، ثم يرسَل الرمز داخل بيانات الاستدعاء. لا يُرسل إلى مزود تحليلات ولا يُكتب في سجل التطبيق. مفتاح التوقيع في Secret Manager، وليس ملف الواجهة.
