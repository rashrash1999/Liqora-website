# عقد العمليات الخادمية

تستخدم الواجهة Firebase Callable SDK. يتحقق الغلاف من ID Token وحالة المستخدم الحالية وApp Check في الإنتاج وحد المعدل، ثم تتحقق الخدمة من الملكية والدور وانتقال الحالة. لا تعتمد أي عملية حساسة على قيمة سلطة أو سعر من المتصفح.

## عقود الروابط

- رابط التسجيل العام حتمي للطلب وموقع بـHMAC، ويُخزن SHA-256 فقط.
- الرابط الشخصي يرتبط بالطلب والضيف والجوال وإصدار الرابط. تدويره يحذف الربط القديم.
- التذكرة مشتقة من الرابط الشخصي والطلب والضيف بسر خادمي، لكنها رمز مستقل.
- جميع الرموز في الواجهة تأتي داخل fragment مثل `#token=...` لتقليل تسربها في سجلات الاستضافة.
- من يمتلك الرابط الشخصي يمتلك صلاحيته؛ لا يُعامل وحده كإثبات هوية حكومي.

## عقد التقرير المرقّم

طلب:

```json
{ "orderId": "...", "pageSize": 500, "cursor": null }
```

استجابة:

```json
{
  "order": { "id": "...", "guestCount": 800 },
  "guests": [],
  "nextCursor": "guest-id-or-null"
}
```

تكرر الواجهة الطلب حتى يصبح `nextCursor` فارغًا، وبحد أقصى 25 صفحة. أرقام الجوال الكاملة لا توجد في مستند الضيف الذي يراه المتصفح، بل تُجمع خادميًا بعد فحص الملكية.

## ضمانات الدفع

- العملة `SAR` وكل المبالغ أعداد صحيحة بالهللات.
- السعر الفردي محسوب خادميًا؛ باقة الأعمال لا تُدفع قبل عرض إداري معتمد غير منتهٍ.
- لا يأتي الإجمالي أو `paid` من المتصفح أو query string.
- `MOYASAR_SECRET_KEY` في Secret Manager فقط.
- يُطابق الخادم الفاتورة والمحاولة والطلب والمبلغ والعملة وحالة المزود.
- التكرار لا يضاعف الفاتورة أو التحول. فاتورة مدفوعة ثانية لطلب مدفوع ترفع `paymentReviewRequired`.

## عقد WhatsApp

- لا يُقبل إلا رقم سعودي E.164 وقالب داخلي اسمه `invitation` أو `reminder`.
- يربط الخادم الاسمين بمعاملَي القالبين المعتمدين في Meta؛ لا يسمح للمتصفح بتمرير اسم قالب.
- سجل `deliveryLogs` له حالات `sending` و`sent` و`failed` وقفل مؤقت.
- إعادة الطلب تتجاوز الرسائل `sent`، وتعيد محاولة الفاشلة دون إعادة الناجحة.
- التذكير يرسل فقط إلى `pending` و`yes`، وليس المعتذر أو قائمة الانتظار.

## أخطاء المجال

`unauthenticated`، `permission-denied`، `invalid-argument`، `failed-precondition`، `already-exists`، `not-found`، `aborted`، `resource-exhausted`، و`unavailable`.
