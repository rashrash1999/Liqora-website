# قائمة قبول الإطلاق

لا تُستخدم مفاتيح Live ولا تُستقبل طلبات مدفوعة حتى تصبح كل البنود المناسبة مؤشرة.

## آليًا

- [ ] `npm ci`
- [ ] `npm test` دون فشل
- [ ] `npm run test:integration` مع Java 21 دون فشل
- [ ] `npm audit --omit=dev` دون تنبيه عالي أو حرج غير مقبول
- [ ] `npm run build` ينتج `dist` ولا ينسخ أسرارًا أو اختبارات
- [ ] GitHub Actions خضراء على commit الإنتاج

## Firebase

- [ ] Phone Auth وEmail/Password وApp Check مفعلة
- [ ] النطاقات النهائية فقط في Authorized domains وCORS
- [ ] القواعد والفهارس وStorage والدوال منشورة
- [ ] TTL مضبوط على `rateLimits.expiresAt`
- [ ] أدوار admin/gate وتعيينات البوابات مختبرة بحسابات منفصلة
- [ ] تنبيهات الميزانية والسجلات والأخطاء مفعلة

## الدفع

- [ ] نجاح وفشل وإلغاء وانتهاء ورجوع في Moyasar Sandbox
- [ ] Callback مكرر وخارج الترتيب لا يضاعف الحالة
- [ ] اختلاف المبلغ أو العملة أو الطلب يُرفض
- [ ] عميل آخر لا يقرأ أو يزامن الفاتورة
- [ ] سياسة الإلغاء والاسترداد معتمدة قانونيًا ومعلنة
- [ ] تسوية يومية أولية بين Moyasar وFirestore موثقة
