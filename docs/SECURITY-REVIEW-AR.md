# مراجعة الأمان وحالة الإصدار — 26 سبتمبر 2026

## الخلاصة

هذه مراجعة للمصدر واختبارات محلية، وليست اختبار اختراق للخدمة المنشورة أو اعتمادًا قانونيًا. أُغلقت المخاطر المنطقية المعروفة في النسخة الأصلية، لكن التشغيل التجاري يظل مشروطًا بنجاح اختبارات Firebase التجريبية والخدمات الحقيقية المذكورة أدناه.

## التحقق المنفذ في بيئة التسليم

- نجح `npm test`: عدد **36/36** اختبارًا، بلا فشل أو تخطٍ.
- نجح بناء موقع الإنتاج: **15 صفحة HTML** في `dist`.
- نجح فحص جميع المراجع المحلية والملفات المرتبطة.
- نجح `npm audit --omit=dev` دون ثغرات مسجلة وقت الفحص.
- نجح فحص تركيب JavaScript لكل ملفات المصدر.
- لم يبدأ اختبار Firebase Emulator هنا لأن Firebase CLI الحالي يتطلب Java 21 بينما بيئة التسليم توفر Java 17. سير GitHub Actions مضبوط على Java 21، ونجاحه شرط نشر.
- اختبارات DOM تتحقق من المتحكمات والحقول والحالات، لكنها ليست بديلًا عن فحص بصري وتفاعلي على هاتف وحاسوب حقيقيين.

## حدود لا يجوز إخفاؤها

1. يجب اختبار SMS وreCAPTCHA Enterprise وApp Check في مشروع Firebase تجريبي مع تفعيل الفوترة والقيود الفعلية.
2. يجب اختبار Moyasar Sandbox للنجاح والفشل والإلغاء والتكرار والـCallback قبل استخدام مفتاح Live.
3. يجب إنشاء قوالب Meta المطابقة وترتيب متغيراتها، واختبار WhatsApp على رقم تجريبي، وضبط إصدار Graph المدعوم وقت النشر.
4. روابط الدعوة والتذاكر صلاحيات حاملها؛ من يحصل على الرابط يستطيع استخدامه. إجراء البوابة يجب أن يطابق الاسم عند الحاجة.
5. فحص توقيع الملف ليس فحص برمجيات ضارة. إن سُمِح لاحقًا بملفات من مصادر غير موثوقة فأضف فحصًا متخصصًا أو تحويلًا آمنًا.
6. التصميم المخصص والفيديو خدمات بشرية: النظام يدير الطلب والملف والاعتماد، ولا يولدهما تلقائيًا.
7. الاسترداد والفاتورة الضريبية وسياسة الحذف والاحتفاظ والنسخ الاحتياطي تحتاج إجراءات تشغيل واعتمادًا قانونيًا ومحاسبيًا.
8. رابط التصميم الموقّع يتطلب صلاحية توقيع V4 لهوية تشغيل الدوال؛ لا تجعل الحاوية عامة إذا غابت الصلاحية.

## بوابة الإطلاق

لا تُنقل المنصة إلى الإنتاج إلا بعد اكتمال قائمة `ACCEPTANCE-CHECKLIST-AR.md`، ونجاح CI ومحاكيات Firebase، واختبار الخدمات الخارجية، وفحص الهاتف والمتصفح، ومراجعة السجلات والتنبيهات والميزانية. لا يمكن لأي مراجعة مصدر أن تضمن انعدام جميع الأخطاء أو الثغرات؛ المعيار المهني هو اختبارات متعددة الطبقات ومراقبة بعد النشر.
